Four steps to start

Install the packs you need once, then append any material whenever you need it.

1. Unzip the pack

Unzip the Asset Library file of a pack. Keep its folders together: texture paths are relative.

2. Add the library

Edit › Preferences › File Paths › Asset Libraries. Press +, then choose the pack folder.

3. Append, do not link

Set the import method to Append (Reuse Data).

4. Drop it on your object

Drag a material from the Asset Browser onto any object.

Built to be adjusted

  • Shared node groups – DSP Mapping, DSP Roughness and DSP Height are the same in every pack, so the packs can be mixed.
  • Built on the pack’s own maps – every material uses the Base Color, Normal, Roughness and Displacement maps of its pack.
  • Catalogs – each pack sorts its materials into Asset Browser catalogs by category.
  • Relative texture paths – the packs find their textures wherever the folder sits.
  • Preview on every material – each material in the Asset Browser has a preview render, and each one is shown on this page.

Requirements & install

  • Blender: 5.x. The materials are Cycles materials; Toon NPR is built for EEVEE.
  • Install: one Asset Library per pack. Import method: Append (Reuse Data).
  • Geometry: displacement materials need dense geometry. See the README of each pack.
  • Files: keep each pack’s folder together, the texture paths are relative.

FAQ

Do I need every pack?

No. Each pack is its own Asset Library. Install only the packs you use.

Where are the previews?

Every material is shown on this page. The preview files are in the Previews folder, one sub-folder per pack.

Which Blender version?

Blender 5.x, with Cycles. Toon NPR is built for EEVEE.
